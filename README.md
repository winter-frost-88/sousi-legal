# Sousi Legal and Support

Public privacy policy, terms of use, and support pages for the Sousi iOS app.

Canonical pages:

- <https://winter-frost-88.github.io/sousi-legal/privacy/>
- <https://winter-frost-88.github.io/sousi-legal/terms/>
- <https://winter-frost-88.github.io/sousi-legal/support/>

The HTML is generated from the Sousi application repository with
`scripts/build_legal_site.ts`. Support form submissions are accepted by the
rate-limited Sousi backend; this repository contains no credentials or private
application source.
